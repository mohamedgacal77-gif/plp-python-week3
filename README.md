# Week 3 Assignment: Conditions and Loops

This repository contains my Week 3 Python assignment on conditions and loops.

- `grade_reporter.py`: Uses conditions and a loop to assign grades, count passes and failures, and calculate the average score.
- `bug_hunt.py`: Fixes a broken while loop program that calculates the sum of numbers from 1 to 5.

The hardest bug to find was the loop condition because it did not produce an error message. The program ran successfully but stopped before adding 5, so the answer was 10 instead of the required 15. I knew something was wrong by comparing the program's output with the expected sum of 1, 2, 3, 4, and 5.
